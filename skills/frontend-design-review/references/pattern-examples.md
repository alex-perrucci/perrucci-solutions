# Pattern Examples

## Good
A clear aesthetic direction with typography, spacing, composition and interaction all serving the same idea.

## Bad
Overused fonts, cliched palettes, centered generic hero, repeated same-size cards, arbitrary gradients/glows and decoration unrelated to the subject.

## Quality Craft
Good work uses a coherent token system, distinctive typography, keyboard accessibility and responsive reflow. Bad work hardcodes random values and breaks at intermediate widths.
