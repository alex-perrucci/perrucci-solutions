# Review Type Modifiers

## PR Review
Focus on implementation, component/token usage and accessibility in code.

## Creative Frontend Review
Focus on conceptual direction, typography, distinctiveness, motion and whether complexity matches the vision.

## Design Review
Focus on flows, hierarchy, navigation, action hierarchy and design-system alignment.

## Accessibility Audit
Focus on keyboard, screen readers, contrast, ARIA and zoom/reflow.

## Design System Compliance Audit
Focus on component variants, tokens, spacing, colors, typography and documented deviations.
