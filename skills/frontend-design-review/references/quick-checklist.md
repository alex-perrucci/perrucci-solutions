# Quick Checklist

Before approving UI work:

## Aesthetic Quality
- [ ] Clear conceptual direction rather than generic AI styling
- [ ] Distinctive typography
- [ ] Cohesive color palette expressed as tokens
- [ ] Intentional motion
- [ ] Interesting but purposeful composition
- [ ] Atmosphere/details support the concept
- [ ] Complexity matches the vision

## Frictionless
- [ ] Core task is efficient
- [ ] Primary action is obvious

## Quality Craft
- [ ] Reusable design tokens/components
- [ ] Responsive and accessible
- [ ] Keyboard navigation works
- [ ] Focus states are visible
- [ ] Reduced-motion is respected

## Trustworthy
- [ ] No fabricated claims or proof
- [ ] Errors are actionable
